# Security policy

Portfolio Analyser handles sensitive financial information. Please do not report a suspected vulnerability in a public issue or attach real portfolio data to a report.

Before opening the repository publicly, enable GitHub private vulnerability reporting, dependency-graph alerts, and secret-scanning push protection in the repository settings. The CI workflow also runs a secret scan on pushes and pull requests.

For a vulnerability, use GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the repository owner privately through GitHub. Include affected versions, reproduction steps, and impact; redact account details, credentials, and personal data. Please allow time for a fix before public disclosure.

The project supports the latest source release. Older copies may not receive security fixes. Users should keep the application and its dependencies current, use a strong app passphrase, protect exported plaintext snapshots, and avoid exposing the local service to untrusted networks.
